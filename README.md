# 亚马逊棋 (Amazons)

10×10 棋盘上的领地争夺棋：双方各 4 枚"亚马逊"（皇后），每回合走一步 =
**按皇后走法移动一枚棋子**，然后**从新位置按皇后走法射出一箭**（箭落地成永久障碍）。
一方的棋子全部无路可走即判负。纯 Python 标准库，零依赖。

## 玩法

```
$ python3 -m amazons
```

每回合输入三个坐标：`起点 落点 箭落点`，例如 `d7 d4 d4`（箭可以射回起点）。
坐标用国际象棋记法：`a1` 左下角 … `j10` 右上角。`q` 退出。

```
    a b c d e f g h i j
10  · · · ♕ · · ♕ · · ·
 9  · · · · · · · · · ·
 ...
 1  · · · ♛ · · ♛ · · ·
```

## 自动演示

```
$ python3 -m amazons --auto --games 10 --seed 7
第 1/10 局: 黑无棋可走, 白胜 (79 半回合)
...
自动演示结束: 共 10 局, 白胜 6, 黑胜 4, 和棋 0
```

AI 是 1 步贪心：枚举全部走法，选择"己方机动 − 对方机动"（皇后可达空格数）最大的走法，平局随机。

## 诚实局限

- **AI 很弱**：只是 1 步贪心启发式，不做深层搜索；熟悉棋理的人类通常能赢
- 和棋计数恒为 0：亚马逊棋中箭不断填满棋盘，对局必然以一方无棋可走结束，实际不存在和棋
- 文本回合制界面，无图形/动画/存档/悔棋
- Python 3.10+，纯标准库
